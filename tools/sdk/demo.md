# GT-DOS Rich Text

This is **bold**, *italic*, `inline code`, and a [link](https://example.com).

## Lists and Quotes

- Arrays, structs and unions
- switch / case / default
- typedef, enum, sizeof

> Rich text is rendered by the kernel and works on VGA and serial.
